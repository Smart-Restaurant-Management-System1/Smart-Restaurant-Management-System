# Smart Restaurant Table Reservation & Order Management System

SE3022 Case Study Project — Year 3 Semester 1

## Technology Stack
- Frontend: React.js + Vite
- Backend: ASP.NET Core Web API
- Data Access: ADO.NET (direct SQL)
- Database: MySQL
- Architecture: Microservices
- Version Control: GitHub
- Testing: Unit Tests, Selenium, JMeter
- CI/CD: GitHub Actions
- Deployment: Azure App Service and/or Docker
- Monitoring: Prometheus + Grafana

## Microservices
- Identity Service — users, authentication, roles, profiles
- Reservation Service — tables, availability, reservations
- Order Service — menu, orders, kitchen workflow
- Billing & Report Service — billing, payments, invoices, reports

## Sprint Plan
1. Sprint 1 — Foundation, Authentication & Table Management
2. Sprint 2 — Reservation Management
3. Sprint 3 — Menu, Ordering & Kitchen Management
4. Sprint 4 — Billing, Payments, Reports, Testing & Deployment

## Important
Implementation source files (.cs, .jsx, .sql, etc.) are intentionally not included.
